# Süße Träume
' A tribute to my Dota loving friend Vikas.'

When the room light turns off, an LED lights up for 2 minutes and a speaker says "Süße Träume."

## Components
- Raspberry Pi Pico W
- GL5528 LDR + 10kΩ resistor (light sensor)
- LED + 220Ω resistor
- DFPlayer Mini 
- Speaker 8Ω
- Micro SD card with `0001.mp3` — a recording of "Süße Träume"
